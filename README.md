# VERTICA
A fully customizable EssentialsX alternative.

**WHY VERTICA?**

Vertica is great when it comes to customisation and modernness. We use action bars instead of chat because it's way more modern and way less cluttered. We have customisable sound effects and customisable messages.

**FEATURES**

Vertica has a lot of cool and useful features including commands like /fly and /mute and features like MOTD customisation and traction control (Join/leave messages / 1st join messages) + more features are coming soon!

**DEFAULT PERMISSIONS**

- /heal [player] >>> vertica.heal
- /feed [player] >>> vertica.feed
- /fly [player] >>> vertica.fly
- /vertica (reload, update) >>> vertica.reload/update
- /mute & /unmute >>> vertica.mute & vertica.unmute
- /freeze & /unfreeze >>> vertica.freeze & vertica.unfreeze
